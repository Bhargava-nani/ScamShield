# 🛡️ ScamShield — SFIC 2026

**Spot the scam. Stay safe. Think before you click.**

ScamShield is a privacy-first scam awareness web application designed to help users recognize possible warning signs in suspicious messages.

Built by **Nani** as a cybersecurity learning project for **SFIC 2026**, ScamShield aims to make online safety awareness more accessible through a simple, beginner-friendly interface.

## ✨ Current Features

- 🔎 Basic rule-based detection of suspicious phrases
- ⚠️ Displays possible warning signs found in a message
- 🧹 Clear button to reset the input and results
- 🔒 Browser-based analysis without sending messages to a server
- 📱 Responsive layout for smaller screens
- ♿ Accessible labels and keyboard focus indicators

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a fictional suspicious message.
5. Click **Analyse** to see the result.
6. Click **Clear** to reset the form.

No backend server is required for the current version.

## 🧪 Testing

The initial detection version has passed four manual checks:

- Empty input validation
- Detection of configured warning phrases
- Handling of messages without matching phrases
- Clear button functionality

## 🔐 Privacy and Security

ScamShield currently processes the entered message locally in the browser. The application does not send the message to a server or intentionally store it.

- Never paste passwords, authentication codes, banking details, or other sensitive information into a demonstration.
- Use fictional messages for testing.
- Treat all results as preliminary guidance, not proof.

## ⚠️ Limitations

ScamShield currently uses basic phrase matching. It can miss scams that use different wording and may flag legitimate messages.

**A message with no detected warning phrases is not necessarily safe.** Always verify requests through trusted, independent channels before clicking links, transferring money, or sharing information.

ScamShield is an awareness and educational tool, not a guarantee of scam detection.
